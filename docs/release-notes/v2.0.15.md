## 2.0.15 — ATXP + n8n integrations

This release activates two new external integration paths in MALACHI OVERDRIVE while preserving the stability and model-truth guarantees from 2.0.14.

- **ATXP provider:** Goal, Loop and API-backed planning can use ATXP's OpenAI-compatible LLM gateway at `https://llm.atxp.ai/v1`. The user supplies their own reusable ATXP connection string, which MALACHI OVERDRIVE stores only through OS-backed secure credential storage and sends as the Bearer credential from the main process.
- One-time ATXP OAuth authorization URLs containing transient `state`, PKCE `code_challenge`, client or redirect parameters are rejected instead of being persisted or shared across users.
- ATXP model discovery reads the gateway's model catalogue and keeps ATXP and OpenRouter selections in separate provider-owned state, so changing provider cannot reinterpret one provider's model id as another provider's model.
- **n8n Automation plugin:** the reviewed plugin catalogue now includes n8n for an existing n8n Cloud or self-hosted instance. Users enter their own instance-level Streamable HTTP endpoint ending in `/mcp-server/http` and an MCP access token; the token is stored as an encrypted plugin credential and is sent only as the Authorization Bearer header.
- MALACHI OVERDRIVE does **not** bundle or redistribute the n8n source repository. The integration connects to n8n's own MCP server, so n8n remains separately deployed and governed by its own account, service and Sustainable Use / Enterprise license terms.
- Provider switching preserves the existing OpenRouter selection, starts a first ATXP switch from the documented `gpt-4.1` reference model, and keeps later ATXP selections independently.
- Regression coverage includes ATXP gateway transport, missing-credential refusal, model listing and cache isolation, secure connection storage, OAuth-link rejection, provider switching, n8n dynamic endpoint/token handling, plugin catalogue/legal inventory, renderer settings and full packaging checks.

The native source download accompanies the installers and is covered by the release checksums.

> **macOS:** publisher-unsigned and unnotarized in 2.0.15; verify the checksum. Requires macOS 13 Ventura or newer. Automatic macOS self-replacement remains intentionally disabled until the separate Developer ID signing/notarization work is completed, because changing ad-hoc code identity can invalidate Accessibility and Screen Recording consent.
> **Linux:** use the AppImage for zero-manual self-updates. The `.deb` remains owned by the system package manager. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

ATXP and n8n are external services/software. Their availability, usage limits, billing, account permissions and upstream behavior remain controlled by those providers. MALACHI OVERDRIVE stores only the credentials each user explicitly enters and keeps them out of renderer state, ordinary config files, URLs and logs.
