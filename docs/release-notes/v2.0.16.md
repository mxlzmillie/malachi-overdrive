## 2.0.16 — GitHub tool library

This release adds five reviewed GitHub projects to MALACHI OVERDRIVE while keeping execution, licensing and security boundaries explicit.

- **free-for.dev** is available as a built-in resource directory for discovering free developer, cloud, infrastructure and API tiers. It is linked to the maintained upstream repository rather than copied into the app.
- **Public APIs** is available as a built-in API directory. MALACHI OVERDRIVE opens the maintained upstream MIT-licensed catalogue so users can browse the current list without shipping a stale snapshot.
- **EasySpider** is available as an external browser-automation/data-collection application with direct project and release links. Its AGPL-3.0 runtime is not bundled or vendored into MALACHI OVERDRIVE.
- **Awesome MCP Servers** is available as a built-in discovery directory for community Model Context Protocol servers. It remains an upstream MIT-licensed catalogue; individual servers still require their own review and installation.
- **Strix** is available as an explicit opt-in application-security resource. The app can show and copy Strix's documented `npx skills add usestrix/strix` setup command, but does not run the command, install Strix, start Docker, or launch any security assessment automatically. Users must only test applications and systems they own or are explicitly authorized to test.
- The Plugins search now covers the GitHub tool library, and each entry has a detail view with its upstream source, license/terms boundary, setup links and relevant safety notice.
- All five entries use original MALACHI OVERDRIVE artwork. Product names identify independent upstream projects and do not imply endorsement or affiliation.
- Regression coverage proves these cards never call the plugin installer, EasySpider stays external, and Strix remains copy/open only until the user deliberately performs its upstream setup.

- `MALACHI-OVERDRIVE-Setup-x64.exe` — Windows x64
- `MALACHI-OVERDRIVE-Setup-arm64.exe` — Windows on Arm

- `MALACHI-OVERDRIVE-macOS-arm64.dmg` · `MALACHI-OVERDRIVE-macOS-arm64.zip` — macOS Apple silicon
- `MALACHI-OVERDRIVE-Linux-x64.AppImage` · `MALACHI-OVERDRIVE-Linux-x64.deb` — Linux x64
- `MALACHI-OVERDRIVE-Linux-arm64.AppImage` · `MALACHI-OVERDRIVE-Linux-arm64.deb` — Linux ARM64
- `MALACHI-OVERDRIVE-Extension.zip` — standalone Chrome companion extension
- `MALACHI-OVERDRIVE-Native-Sources.tar.gz` — native image-library sources, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies the installers and is covered by the release checksums.

> **macOS:** publisher-unsigned and unnotarized in 2.0.16; verify the checksum. Requires macOS 13 Ventura or newer. Automatic macOS self-replacement remains intentionally disabled until the separate Developer ID signing/notarization work is completed, because changing ad-hoc code identity can invalidate Accessibility and Screen Recording consent.
> **Linux:** use the AppImage for zero-manual self-updates. The `.deb` remains owned by the system package manager. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

The GitHub tool library is a reviewed navigation/setup surface, not a claim that MALACHI OVERDRIVE owns or redistributes those projects. External projects keep their own licenses, accounts, service terms, runtimes and operating-system permissions.
