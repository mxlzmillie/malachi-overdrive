## 2.0.20 — Ambient Edge background work

This beta release introduces Ambient Edge: a quieter way to watch MALACHI OVERDRIVE work without surrendering the conversation or having worker tabs interrupt the browser.

- **Background work stays out of the way.** Worker chats are placed in MALACHI OVERDRIVE's dedicated, unfocused background window regardless of the general chat-opening preference. Routine worker creation no longer adds a tab to the user's active browser window or changes the selected page. Opening a linked chat remains an explicit user action.
- **A slim live capsule replaces constant dashboard pressure.** Ambient Edge stays at the far-right edge and exposes the real run state, elapsed time and a new-task action while leaving the conversation at full size.
- **The compact preview uses operational truth.** Expanding the capsule shows the active task, latest structured activity, active-worker count and recorded outputs. It deliberately avoids fake progress percentages and illustrative previews when no verified preview exists.
- **The detailed workbench is still available on demand.** “Open workbench” reveals the full Control Rail with outputs, workers, activity, files, browser state, queues, sources and issues. Closing the compact preview restores keyboard focus without changing the current draft or scroll position.
- **Completion is quiet and non-blocking.** A small dismissible alert appears after a genuine transition to complete and disappears automatically. Reduced-motion users receive the same state without the live ring animation.

### Validation

The focused renderer, worker-placement and background-window suites passed 319/319 tests. The complete verification suite passed 141 ordinary test files plus the isolated shutdown suite, with 3,489 ordinary tests and 2 shutdown tests passing. The production Electron renderer was built and captured at 1440 × 900 and 390 × 844; both Ambient Edge layouts fit without horizontal overflow, kept the composer visible, used no modal scrim, made no forbidden fixture actions or external requests, and reported zero renderer console errors. The full release workflow retains strict checksum, native corresponding-source, platform packaging, Developer ID signature and Apple notarization gates.
