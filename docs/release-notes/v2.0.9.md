## MALACHI OVERDRIVE bootstrap auto-update release

## 2.0.9

- MALACHI OVERDRIVE is now the current user-facing name across the desktop app, companion extension, connector names, installer metadata and release artifacts.
- Windows and Linux AppImage installs automatically check for a newer release, download the exact platform/architecture artifact, verify it against the release `SHA256SUMS.txt`, and stage it without interrupting work.
- Once a staged update has been ready for at least five minutes, MALACHI OVERDRIVE can restart itself automatically only when the laptop has been idle for at least two minutes and there are no live browser turns, in-flight MCP requests or retained terminal processes.
- Windows uses the electron-builder NSIS silent upgrade path and force-run restart contract. Linux AppImage replacement prefers an atomic rename and falls back to a bounded copy only across filesystems.
- Each release build trusts only the GitHub repository that built it. A local build with no baked release repository performs no network update check, preventing a private/branded build from silently following an unrelated upstream project.
- The packaged Chrome companion is re-materialized into its stable user-data folder during app startup, so the desktop update also refreshes the companion files. A browser process already running old extension code may still require its normal runtime/tab refresh after a protocol-changing release.
- Existing 2.0.8 private installs carrying the old update-disable marker need this release once as the bootstrap. After 2.0.9 is installed, future eligible Windows/AppImage releases can arrive without a manual installer replacement.

### Downloads

- `MALACHI-OVERDRIVE-Setup-x64.exe` — Windows x64
- `MALACHI-OVERDRIVE-Setup-arm64.exe` — Windows on Arm
- `MALACHI-OVERDRIVE-macOS-x64.dmg` · `MALACHI-OVERDRIVE-macOS-x64.zip` — macOS Intel
- `MALACHI-OVERDRIVE-macOS-arm64.dmg` · `MALACHI-OVERDRIVE-macOS-arm64.zip` — macOS Apple silicon
- `MALACHI-OVERDRIVE-Linux-x64.AppImage` · `MALACHI-OVERDRIVE-Linux-x64.deb` — Linux x64
- `MALACHI-OVERDRIVE-Linux-arm64.AppImage` · `MALACHI-OVERDRIVE-Linux-arm64.deb` — Linux ARM64
- `MALACHI-OVERDRIVE-Extension.zip` — standalone Chrome companion extension
- `MALACHI-OVERDRIVE-Native-Sources.tar.gz` — native image-library sources, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies the installers and is covered by the release checksums.
Installed notices link to it and explain the LGPL/MPL components and library replacement.

> **macOS:** publisher-unsigned and unnotarized in 2.0.9; verify the checksum. Requires macOS 13 Ventura or newer. Automatic macOS replacement is intentionally disabled until releases have a stable Developer ID signature and notarization, because changing ad-hoc code identity can invalidate Accessibility and Screen Recording consent.
> **Linux:** use the AppImage for zero-manual self-updates. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`. The `.deb` remains owned by the system package manager and therefore does not replace itself silently.

Core and the workspace support Windows, macOS and Linux. Desktop screen/input control is available on Windows and optionally macOS with Screen Recording and Accessibility permissions. External plugins run with their own OS or service permissions and do not inherit approved-folder restrictions. Hosted-service terms and account limits apply. This project remains beta.
